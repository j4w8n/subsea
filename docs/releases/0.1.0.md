# Subsea 0.1.0

Subsea 0.1.0 is the first public release. It establishes x86-64 Linux as the stable host and `x86` as the stable target while making the AArch64 and freestanding work available for experimentation.

## Install

The release asset is a prebuilt binary. GNU `as` and `ld` are required when building stable x86 programs.

```sh
version=0.1.0
asset="subsea-${version}-x86_64-linux.tar.gz"
base="https://github.com/j4crev/subsea/releases/download/v${version}"
curl -fLO "$base/$asset"
curl -fLO "$base/$asset.sha256"
sha256sum --check "$asset.sha256"
tar -xzf "$asset"
sudo install -m 0755 subsea /usr/local/bin/subsea
```

The archive is named `subsea-0.1.0-x86_64-linux.tar.gz`. GNU `objcopy` is required only for the experimental freestanding `--format binary` option.

## Highlights

- Readable assignment syntax over real target registers and memory.
- Integer and scalar floating-point operations, explicit widths, comparisons, casts, and typed intrinsics.
- Functions, local labels, indirect calls/jumps, imports, stack storage, layouts, and explicit static data sections.
- Linux printing, reading, virtual-memory reservation/release, raw syscalls, and process exit.
- Annotated assembly output for auditing and learning.
- Side-by-side Subsea and x86-64 assembly examples.

Every program begins at source-level `main`, emitted as `_start` by default. Since `main` has no caller, it cannot `ret`; all reachable paths must exit or transfer control without returning.

## Target Status

| Target | Status |
| --- | --- |
| `x86` | Stable x86-64 Linux userland |
| `x86-free` | Experimental x86-64 freestanding |
| `aarch` | Experimental AArch64 Linux userland |
| `aarch-free` | Experimental AArch64 freestanding |

Implementation parity does not imply release stability. The experimental targets may have incomplete host toolchain and runtime coverage or may change in later releases.

## Known Limitations

- Runtime floating-point printing is not implemented.
- Raw binaries are not independently bootable.
- Experimental AArch64 and freestanding targets are not covered by the stable support commitment.
