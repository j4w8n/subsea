# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

Experimental targets are accepted for security review, but fixes and release timing may differ from the stable `x86` target.

## Reporting A Vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/j4crev/subsea/security/advisories/new). This keeps the report and follow-up discussion private while maintainers investigate.

Include the affected version and target, a minimal reproducer or malformed input when safe, the observed impact, and any suggested mitigation. Do not open a public issue, discussion, or pull request for an undisclosed vulnerability.

Maintainers will acknowledge the report through the private advisory, assess its impact, and coordinate a fix and disclosure there. Please allow a reasonable investigation period before publishing details.
